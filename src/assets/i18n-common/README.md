# Common texts

This folder contains commonly used translateable texts which are not part of any Element component.
These texts are used in our examples but unlike the texts in the `src/assets/i18n/` folder, they are
reusable and distributed via our Siemens-internal language packs.

Texts in the `template-i18n.json` will be picked up by the Siemens internal translation platform, rewritten by UX writers, translated and returned as `<language>.json`.
