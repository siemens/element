SIEMENS ELEMENT
FORMLY MIGRATION

Before → after

Replace module setup with the standalone component

Before Element 50 · Formly 6
import { SiFormlyModule } from
  '@siemens/element-ng/formly';

@NgModule({
  imports: [SiFormlyModule.forRoot()]
})
export class AppModule {}
After Element 51 · Formly 7.1
import { SiFormlyComponent } from
  '@siemens/element-ng/formly';

@Component({
  imports: [SiFormlyComponent],
  template: `<si-formly [fields]="fields" />`
})
export class ProfileForm {}
Staying on v6 for now? Import @siemens/element-ng/formly-legacy, then plan the v7.1 migration before the legacy package is removed.

Before single config
onClosed(
  config:
    | Omit<WidgetConfig, 'id'>
    | undefined
) {
  if (config) {
    this.addWidget(config);
  }
}
After array of configs
onClosed(
  configs:
    | Omit<WidgetConfig, 'id'>[]
    | undefined
) {
  configs?.forEach(config =>
    this.addWidget(config)
  );
}

This signature change matters when extending SiWidgetCatalogComponent or consuming (closed) directly. In single-select mode, the array contains one item.
